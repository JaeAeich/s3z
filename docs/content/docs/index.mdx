A lightweight, high-throughput S3 library built in Rust with bindings for
Python, Node.js, and the CLI. No AWS SDK — just raw HTTP, SigV4 signing,
and parallel streaming.

Works with **any S3-compatible backend** — AWS S3, MinIO, SeaweedFS, Garage,
and more.
